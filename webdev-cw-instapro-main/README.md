# InstaPro

## Описание проекта
InstaPro — социальная сеть для обмена фотографиями, аналог популярной социальной сети. Проект разработан с использованием ванильного JavaScript, HTML и CSS, и взаимодействует с существующим API.

## Реализованная функциональность
- Регистрация и авторизация пользователей
- Просмотр ленты постов всех пользователей
- Добавление новых постов с описанием и фотографией
- Просмотр страницы с постами конкретного пользователя
- Лайки и дизлайки постов
- Отображение количества лайков для каждого поста
- Загрузка фотографий в облачное хранилище

## Что было доработано
1. **Интеграция списка постов с API**: Реализовано отображение постов из API с правильным форматированием данных.
2. **Страница добавления поста**: Создана полностью функциональная форма добавления поста с возможностью загрузки фотографий и добавления описания.
3. **Страница с постами пользователя**: Реализована страница для просмотра всех постов конкретного пользователя.
4. **Функционал лайков**: Добавлена возможность ставить и убирать лайки, с обновлением интерфейса в реальном времени.

## Как запустить проект на Windows 11

### Предварительные требования
- Установленный Node.js (скачать можно с [nodejs.org](https://nodejs.org/))

### Шаги для запуска
1. Клонируйте репозиторий:

git clone https://github.com/yourusername/webdev-cw-instapro.git
cd webdev-cw-instapro

2. Установите простой HTTP-сервер:


npm install -g http-server

3. Запустите сервер в папке проекта:

http-server

4. Откройте браузер и перейдите по адресу:

http://localhost:8080

### Возможные проблемы и их решение
- Если в консоли возникают ошибки CORS, убедитесь, что вы запускаете приложение через http-server, а не просто открывая HTML-файл.
- Если возникают проблемы с API, проверьте, что используется правильный personalKey в файле api.js.

## Структура проекта
- `index.html` — основной HTML файл приложения
- `index.js` — основной JavaScript файл, управляющий роутингом и состоянием
- `api.js` — модуль для работы с API
- `helpers.js` — вспомогательные функции
- `routes.js` — константы для маршрутизации
- `/components` — папка с компонентами интерфейса:
- `add-post-page-component.js` — компонент страницы добавления поста
- `auth-page-component.js` — компонент страницы авторизации
- `header-component.js` — компонент шапки сайта
- `loading-page-component.js` — компонент страницы загрузки
- `posts-page-component.js` — компонент страницы со всеми постами
- `user-posts-page-component.js` — компонент страницы постов пользователя
- `upload-image-component.js` — компонент загрузки изображений
- `/assets` — папка с шрифтами и изображениями

## Используемые технологии
- JavaScript (ES6+)
- HTML5
- CSS3
- RESTful API
- localStorage для хранения данных пользователя
